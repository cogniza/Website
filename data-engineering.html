Structured Curriculum & Learning Modules

A comprehensive, step-by-step learning roadmap designed by veteran practitioners.

Module 1: Big Data Foundations & Distributed Computing
  • Hadoop HDFS, MapReduce paradigms, and modern Lakehouse storage
  • Data serialization: Parquet, Avro, ORC
  • Linux shell scripting and cluster setup
Module 2: Apache Spark & Distributed ETL with PySpark
  • Spark RDDs, DataFrames, and Spark SQL optimization
  • Catalyst optimizer, Tungsten execution, and partition tuning
  • PySpark UDFs and distributed joins (Broadcast vs Shuffle)
Module 3: Real-Time Streaming with Apache Kafka & Spark Streaming
  • Kafka topics, partitions, producers, and consumer groups
  • Structured Streaming: watermarks, windowing, and trigger intervals
  • Kafka Connect and schema registries
Module 4: Data Warehousing, Modern Modeling & Orchestration
  • Snowflake architecture: virtual warehouses, zero-copy cloning
  • Dimensional modeling: Star schema, Snowflake schema, SCD Type 1/2
  • Workflow orchestration with Apache Airflow DAGs
Module 5: Capstone Enterprise Real-Time Lakehouse Pipeline
  • Building an end-to-end e-commerce clickstream analytics pipeline
  • Automated anomaly detection, data quality tests with Great Expectations
