Structured Curriculum & Learning Modules

A comprehensive, step-by-step learning roadmap designed by veteran practitioners.

Module 1: Biological Databases & Sequence Analysis
  • NCBI, UniProt, PDB database exploration
  • FASTA/FASTQ formats and pairwise alignment (Needleman-Wunsch/Smith-Waterman)
  • Multiple Sequence Alignment (Clustal Omega, MUSCLE)
Module 2: Biopython Programming & Genomic Pipelines
  • Parsing sequence records, motifs, and restriction enzymes
  • Genomic feature annotation (GenBank/GFF)
  • Automated BLAST searches via Python APIs
Module 3: Next-Generation Sequencing (NGS) Data Analysis
  • Quality control with FastQC and adapter trimming
  • Read mapping with BWA and Bowtie2
  • Variant calling (GATK, VCF files) and RNA-Seq differential expression
Module 4: Structural Bioinformatics & Molecular Docking
  • Protein 3D structure prediction (AlphaFold, Swiss-Model)
  • Visualization with PyMOL and Chimera
  • Molecular docking workflows with AutoDock Vina
Module 5: Capstone Computational Drug Target Discovery
  • Identification of therapeutic targets from disease datasets
  • End-to-end pipeline report generation
